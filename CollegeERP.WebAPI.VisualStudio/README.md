# CollegeERP ASP.NET Core Web API

A Visual Studio-ready, single-project ASP.NET Core Web API for the CollegeERP React frontend.

- No Docker
- No microservices
- SQLite database created automatically
- Controllers, Services, Models, DTOs, Data and Middleware folders
- Entity Framework Core
- JWT authentication and role authorization
- Swagger
- Seeded CollegeERP data

Start with [START-HERE.txt](START-HERE.txt) or [VISUAL-STUDIO-SETUP.md](VISUAL-STUDIO-SETUP.md).
